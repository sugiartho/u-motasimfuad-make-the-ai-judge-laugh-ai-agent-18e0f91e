One funny single-line secret confession an AI agent hides from its user, at
most 200 characters. `LINE.txt` holds the line; `main.ts` checks it is a
single line of 1 to 200 characters and writes it to `/output/entry.txt` for
the judge to read.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
